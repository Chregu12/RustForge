SETUP REQUIREMENTS

  • Or AWS S3 credentials

For Broadcasting:
  • Redis: docker run -p 6379:6379 redis
  • WebSocket port 6001

Dependencies (all added to Cargo.toml):
  • aws-config = "1.5"
  • aws-sdk-s3 = "1.68"
  • tokio-tungstenite = "0.26"
  • redis = { version = "0.27", features = ["tokio-comp"] }
  • deadpool-redis = "0.18"
